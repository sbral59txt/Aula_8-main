PROJETO: RELATORIO DE DESPESAS

Arquivos:
- exer2.html: estrutura da página
- css/exer2.css: aparência da página
- js/exer2.js: cadastro, filtros, totalização e localStorage

COMO EXECUTAR
1. Extraia a pasta relatorio_despesas do arquivo ZIP.
2. Mantenha a organização das pastas.
3. Abra exer2.html no navegador.

FORMATO DOS DADOS
Cada despesa é salva como descricao:valor:data.
Despesas diferentes são separadas por |.
Exemplo:
Mercado:35.9:2026-10-19|Ônibus:5.5:2026-10-19

OBSERVAÇÃO
Os dados são guardados no localStorage do navegador usado para abrir a página.
